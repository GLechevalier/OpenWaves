# OpenWaves - Open Source mmWave Radar

This repo contains all the content you need to get started in mmWaves Radar, it packages an electromagnetic simulation you can play with, the mechanical parts, the electronics and software to run the full material classification end to end demo, and fall detection demo. 

## Set Up



## Install OpenEMS & CSXCAD : 
Windows :
1. Go to : https://github.com/thliebig/openEMS-Project/releases
2. Download openEMS_x64_v0.37.0-rc1_msvc.zip
3. Unzip the content and place in your user/opt dir, create it if needed
4. pip install [PATH_TO_OPT/openEMS/python/]csxcad-0.6.3-cp314-cp314-win_amd64.whl
5. pip install [PATH_TO_OPT/openEMS/python/]openems-0.0.36-cp314-cp314-win_amd64.whl

full tutorial here : https://docs.openems.de/python/install.html
